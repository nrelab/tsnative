# Research Archive

These documents capture the research that informed the TSNative subset, backend, runtime, ABI, and reproducibility decisions.

- [Architecture survey](architecture-survey.md): compiler models, language features, runtime trade-offs, and ABI considerations.
- [Roadmap survey](roadmap-survey.md): staged feature roadmap, backend options, cross-compilation, and ecosystem scope.
- [Native toolchain survey](native-toolchain-survey.md): native TypeScript prior art, LLVM/Cranelift comparisons, runtime services, and conformance strategy.

The authoritative current contract is maintained in [the repository plan](../../PLAN.md), [the subset specification](../subset.md), and [the ABI specification](../abi.md). Historical research should not override those checked-in decisions.
